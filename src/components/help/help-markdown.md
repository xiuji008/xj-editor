# Markdown 语法

本应用基于 marked 渲染，除标准 Markdown 外还支持 Front Matter、GitHub 提示块、数学公式等扩展语法。

## 标题

````markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
````

## 段落与强调

````markdown
普通段落之间用空行分隔。

**粗体文本**　*斜体文本*　***粗斜体***　~~删除线~~　`行内代码`
````

效果：**粗体文本**　*斜体文本*　***粗斜体***　~~删除线~~　`行内代码`

## 列表

````markdown
无序列表：
- 项目一
- 项目二
  - 子项目（缩进两个空格）

有序列表：
1. 第一项
2. 第二项

任务列表：
- [x] 已完成事项
- [ ] 待办事项
````

## 引用

````markdown
> 这是一段引用。
> 可以有多行。
>
> > 支持嵌套引用。
````

## 代码块

用三个反引号包裹，开头反引号后写语言标识可获得语法高亮（详见「代码块语言」）：

`````markdown
```python
def hello():
    print("Hello, XJ-Editor!")
```
`````

## 表格

````markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 单元格 | 单元格 | 单元格 |
| a | b | c |
````

效果：

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 单元格 | 单元格 | 单元格 |
| a | b | c |

## 链接与图片

````markdown
[链接文字](https://example.com)

![图片描述](./images/photo.png)
````

## 分割线

````markdown
---
````

## Front Matter（文档元信息）

文档最顶部用 `---` 包裹的 YAML 块会被渲染为蓝色元信息卡片，AI 的「一键更新元数据」也会维护这些字段：

````markdown
---
title: 文档标题
createDate: 2026-11-12 10:00:00
lastUpdateDate: 2026-11-12 12:00:00
---
````

## GitHub 提示块

引用语法基础上加 `[!类型]` 标记，支持 NOTE / TIP / IMPORTANT / WARNING / CAUTION：

````markdown
> [!NOTE]
> 用于强调用户应该注意的信息。

> [!WARNING]
> 警告：此处操作有风险。
````

效果：

> [!NOTE]
> 用于强调用户应该注意的信息。

## 数学公式（KaTeX）

行内公式用单个美元符包裹，块级公式用两个美元符包裹：

````markdown
行内公式：质能方程 $E = mc^2$ 出现在文字中间。

块级公式：

$$
\int_{a}^{b} f(x)\,dx = F(b) - F(a)
$$
````

效果：质能方程 $E = mc^2$ 出现在文字中间。

$$
\int_{a}^{b} f(x)\,dx = F(b) - F(a)
$$

也可以用 ` ```math ` 或 ` ```mathjax ` 代码块书写块级公式。

## 转义

如果需要显示 Markdown 的特殊字符本身，在前面加反斜杠：

````markdown
\* 不是斜体，而是星号本身
````

效果：\* 不是斜体，而是星号本身

# 功能介绍

XJ-Editor 是一款独立的 Markdown 桌面编辑器（Electron + Vue3 构建），集写作、预览、AI、版本管理与白板于一体。

## 编辑与预览

- **三种视图**：编辑 / 分屏 / 预览，可随时切换（工具栏视图切换按钮）
- **实时预览**：所见即所得的渲染效果，源码与预览同步滚动
- **查找替换**：编辑区与预览区均支持查找（Ctrl+F 查找、Ctrl+H 替换）
- **富文本编辑**：标题、列表、表格、代码块等常用语法一键插入

## 文件管理

- **目录树**：打开文件夹后以目录树浏览，支持新建 / 重命名 / 删除 / 复制粘贴
- **多窗口**：每个文件可开独立窗口，最多同时 8 个主窗口
- **暂存区**：内置固定草稿文件，临时拷贝文字资料，自动保存（Ctrl+Shift+T）
- **文件关联**：可在设置中把 `.md` / `.markdown` / `.board` 等扩展名注册为本应用的默认打开方式
- **支持格式**：Markdown、HTML、JSON、纯文本、白板（.board / .excalidraw）、PDF、Word 预览等

## AI 助手

- **AI 面板**：右侧侧边栏与 AI 对话，可引用选中文本提问
- **快捷指令**：常用提示词一键发送，可在设置中自定义
- **概要生成**：根据当前文档自动生成摘要并插入标题下方
- **元数据更新**：一键生成 / 更新文档 Front Matter 元信息
- **AI 调用日志**：查看每次大模型请求的参数、响应与 Token 用量

## Git 版本管理

- **内置 Git 面板**（Ctrl+Shift+G）：提交 / 比对 / 历史记录 / 分支切换
- **从 Git 打开**：直接克隆远程仓库并打开项目目录
- 未检测到 Git 时会有提示，可在 Git 面板的菜单中手动指定 git.exe 路径

## 内置终端与工具集

- **终端**：在当前目录下打开命令行（Ctrl+\`），也支持调起系统外部终端
- **工具集**（Ctrl+Alt+T）：JSON 格式化、Base64 编解码、时间戳转换、哈希计算等通用小工具

## 白板草图

- 基于 Excalidraw 的无限画布，新建 `.board` 或 `.excalidraw` 文件即可使用
- 支持图形绘制、Ctrl+S 保存、导出 PNG / SVG
- Markdown 中可用 ` ```whiteboard ` 代码块嵌入只读白板

## 图表与公式

- **Mermaid 流程图 / 时序图**、**Chart.js 数据图表**、**PlantUML 图**、**KaTeX 数学公式**，详见「代码块语言」一节

## 导出与主题

- **导出 HTML / Word / PDF**：PDF 支持自定义纸张、方向、页边距、内容缩放与页码
- **双主题**：浅色 / 深色 / 跟随系统，工具栏一键切换
- **代码高亮主题**：多套 highlight.js 配色可选，每篇文章可独立设置

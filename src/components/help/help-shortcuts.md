# 快捷键

> 提示：`Ctrl` 在 macOS 上对应 `Cmd`。

## 文件操作

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+S | 保存当前文件 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+O | 打开文件 |
| Ctrl+Shift+O | 打开目录 |
| Ctrl+N | 新建文件 |
| Ctrl+Shift+N | 新建窗口 |

## 面板与工具

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Shift+T | 打开 / 切换暂存区（内置草稿本） |
| Ctrl+Shift+G | 显示 / 隐藏 Git 版本管理面板 |
| Ctrl+\` | 显示 / 隐藏内置终端 |
| Ctrl+Alt+T | 打开工具集（JSON / Base64 / 时间戳 / 哈希） |
| F1 | 打开帮助文档 |

## 编辑与查找

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |
| Ctrl+F | 查找 |
| Ctrl+H | 查找并替换 |
| F3 | 跳转到下一个匹配项 |
| Shift+F3 | 跳转到上一个匹配项 |
| Esc | 关闭查找 / 替换栏 |

## 其他

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+C | 复制选中文本；无选中时复制目录树中选中的文件 |
| Ctrl+V | 粘贴已复制的文件（目录树操作） |
| F12 | 显示 / 隐藏开发者工具 |
